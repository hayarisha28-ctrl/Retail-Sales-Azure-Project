# Retail Sales Data Engineering Project

This project implements a data pipeline on **Azure** using the Medallion architecture.

## My Contribution (Gold Layer):
- Developed SQL Views to transform cleaned data into business insights.
- Created `vw_kpis`, `vw_top_customers`, and `vw_store_performance`.

## Tools Used:
- Azure SQL Database
- Power BI
- GitHub for Version Control# Retail-Sales-Azure-Project
